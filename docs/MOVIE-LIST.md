# 观影清单格式

`tools/parse_list.py` 接受以下任意格式（可混用），一行一部：

## 1. 最简单

```
肖申克的救赎
低俗小说
千与千寻,2001
```

## 2. 带年份与评分（推荐）

```
肖申克的救赎（1994）★
低俗小说,1994,优秀
```

- 年份写在括号里或逗号后都行；
- 评分关键词（超优秀/优秀/良/中）会自动提取，仅用于展示。

## 3. 观影笔记式（cleanyourtv 风格）

```
#### 怦然心动：0925晚；2010上映；爱情喜剧。评价良
#### 蝙蝠侠黑暗骑士：0823午晚；2008上映；诺兰导演。评价优秀
```

标题后的"观看日期、评论"等笔记会被忽略，只取片名。片名里自带冒号的
（如 `蜘蛛侠：英雄归来：0805晚`）也能正确切分。

## 规则

- 每行一部，重复片名自动去重；
- 片名会作为海报文件名（Windows 非法字符自动映射为全角）；
- 解析结果写入 `data/movies.json`，与已有数据按片名合并——
  **已抓到海报的条目不会被覆盖**。

## 豆瓣用户快捷方式

不想手写清单？装上 Chrome 插件（[extension/](../extension/)）后选
「豆瓣我的影单」，直接按你在豆瓣标记的"看过/想看"整单抓取——
条目号直接来自豆瓣，匹配最准。
